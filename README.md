# AlarmMonitor – Installer und Updates

Öffentliche Windows-x64-Installer für AlarmMonitor von Daniel Delfser. Der Quellcode wird separat privat verwaltet.

[Neueste Version herunterladen](https://github.com/delfser/AlarmMonitor-Updates/releases/latest)

Ab Version 1.0.9: Updateprüfung, Hintergrunddownload und Installation innerhalb der Anwendung unter Hilfe → Programmupdates. Für ältere Installationen ist einmalig der neue Installer nötig. Vorhandene Daten und Einstellungen bleiben beim Update erhalten. Manifest und Paket werden vor automatischer Installation geprüft. Während Installation und Neustart besteht eine kurze Empfangspause.
